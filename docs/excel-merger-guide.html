Excel Sheet Merger

Match two sheets from the same workbook on one or more key columns and bring columns across, using exact, partial or fuzzy matching.

Open Excel Sheet MergerBack to all tools

You need

One workbook (.xlsx, .xlsm, .xls or .csv) that contains both sheets you want to match.

You get

merged_output.xlsx with a sheet named “Merged”. Match statistics and a preview of the first 200 rows appear on screen.

Your file stays in your browser tab. The tool reads and processes it there and does not upload it. The page loads the SheetJS library from cdnjs.cloudflare.com, so it needs an internet connection to open. How privacy works

How to use it

  1. Choose your workbook (drag it onto the upload box or click it). All sheets are read.
  2. Pick Sheet 1 (Left) and Sheet 2 (Right).
  3. Choose the number of matching columns (1, 2, 3 or a custom number) and pick the column from each sheet for every pair.
  4. Choose the match type: Exact, Partial or Fuzzy. For Fuzzy, set the threshold (it starts at 70%).
  5. Choose duplicate handling: return all matches, or first match only.
  6. Choose the merge mode: Inner, Left, Right or Full outer.
  7. Tick the columns to include from Sheet 2, then press Run Merge.
  8. Review the match statistics and preview, then press Download Merged Excel. New Merge clears everything.

How matching works

Match typeA row matches when…
ExactThe key values are identical.
PartialOne value contains the other, ignoring upper/lower case. “ABC” matches “ABC Pvt Ltd”.
FuzzyThe text similarity is at or above your threshold. Similarity is based on the number of character edits between the two values, after trimming spaces and ignoring case.

With several key columns, every pair must match.

Good to know. Partial and fuzzy matching compare each row of Sheet 1 against the rows of Sheet 2, so they get slower as the sheets grow. Both sheets must be in the same workbook; to match across two files, first copy one sheet into the other workbook.

Example

Sheet 1: Vendor CodeSheet 2: Vendor CodeSheet 2: Vendor Name
V001V001ABC Pvt Ltd
V002V002XYZ Pvt Ltd

Matching on Vendor Code and returning Vendor Name adds the vendor name next to each Sheet 1 row.

Frequently asked questions

Can I match on more than one column?

Yes — choose 1, 2, 3 or a custom number of key columns.

What is the difference between the join modes?

Inner keeps only matched rows. Left keeps every Sheet 1 row. Right keeps every Sheet 2 row. Full outer keeps all rows from both.

What does “first match only” do?

If several Sheet 2 rows match one Sheet 1 row, only the first is used. “Return all matches” produces one output row per match.
