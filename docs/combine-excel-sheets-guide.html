Combine Excel Sheets Tool

Stack the first sheet of many Excel workbooks into one file — as separate tabs, or merged into a single sheet.

Open Combine Excel Sheets ToolBack to all tools

You need

A folder (or a set of files) of Excel workbooks: .xlsx, .xls, .xlsm or .xlsb. For the single-sheet option they should share the same column layout.

You get

Combined_Workbook.xlsx (one tab per file) and/or Merged_Single_Sheet.xlsx (one sheet called “Combined”).

Your file stays in your browser tab. The tool reads and processes it there and does not upload it. The page loads the SheetJS library from cdnjs.cloudflare.com, so it needs an internet connection to open. How privacy works

How to use it

  1. Click the upload box (or press Enter on it) to choose a folder, or drop Excel files onto it. To pick individual files, use Choose individual files instead of a folder. Some mobile browsers cannot choose folders; use the individual-files button there.
  2. Check the file list. Files are listed alphabetically by name, and that order is used in the output. Temporary Excel files starting with ~$ and non-Excel files are ignored.
  3. Press Combine Files. Each file shows its status, and a summary shows how many were processed, imported and failed.
  4. Download either Multiple Sheets (one tab per file) or Merged Into One Sheet. Clear resets the tool.

What each output contains

OutputContents
Multiple sheetsThe first sheet of each workbook becomes its own tab, named after the file. Characters Excel does not allow in tab names are replaced with “_”, names are cut to 31 characters, and duplicates get “_1”, “_2”, and so on.
Merged into one sheetThe header row of the first file is kept once; every file’s remaining rows are added underneath, in the listed order. Columns are lined up by position, not by heading, so use it only when all files have the same column order.
Limits to be aware of.
  • Only the first sheet of each workbook is used.
  • Files that cannot be read, or whose first sheet is empty, are skipped and listed after the run.
  • Fonts, colours, borders and number-format styling are not carried across. Column widths and merged cells are kept in the multiple-sheets output, but the single-sheet output contains values only.
  • Please check date and number columns in the single-sheet output against your source files before you rely on it.

Frequently asked questions

Does it work offline?

No. The page needs an internet connection to load the spreadsheet library when it opens. Your files are not uploaded.

Why does my browser say “Upload”?

That is the browser’s standard wording for choosing files. This tool only reads them in your browser tab.

Are files in sub-folders included?

Browsers generally pass along the files from sub-folders when you choose a folder. Check the file list before pressing Combine Files.
