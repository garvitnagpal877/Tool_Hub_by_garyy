PO Splitting Detection Tool

Find purchase orders that may have been split into smaller ones so that each stayed under an approval limit.

Open PO Splitting Detection ToolBack to all tools

You need

A PO dump with PO number, PO date, supplier name and PO value (supplier code is optional), plus an approval matrix you type in or upload.

You get

po_splitting_cases.xlsx with sheets “PO Splitting Cases”, “Daily Summary (Working)”, “Case Details” and “Approval Matrix Used”.

Your file stays in your browser tab. The tool reads and processes it there and does not upload it. The page loads the SheetJS library from cdnjs.cloudflare.com, so it needs an internet connection to open. How privacy works

How to use it

  1. Choose your PO dump (.xlsx, .xlsm, .xls or .csv) and the source sheet.
  2. Map the columns: PO Number, PO Date, Supplier Name and PO Value are required; Supplier Code is optional.
  3. Set the rolling window in days (3 means PO date − 3 to PO date + 3).
  4. Enter the approval matrix (From amount, To amount, Approval level) by hand, or upload it from Excel.
  5. Press Generate PO Splitting Cases, review the cases, and click a Case ID (or press Enter on it) to see the POs inside. Then Export to Excel.

How cases are formed

POs are first grouped by supplier and date. For each supplier, POs whose windows overlap — even in a chain — are merged into one case. A case needs two or more POs. A case is listed only if its aggregate value is above the lowest threshold of your approval matrix.

Cases are labelled by the number of days they span: Same Day, 1 Day, 2 Day, 3 Day, or Multi Day.

Escalation and risk level

Escalation is “YES” when the case’s aggregate value needs a higher approval level than its largest single PO.

RiskRule
LOWThe aggregate falls in the same approval band as the largest single PO.
MEDIUMThe aggregate is in a higher band, but exceeds the largest PO’s band ceiling by less than 25%.
HIGHThe aggregate exceeds that ceiling by 25% or more.

Example

Five POs to one supplier between 13 and 18 March, worth 24,100; 95,000; 102,000; 51,000 and 14,250, with a ±3-day window, form a single case, PS-001, with an aggregate of ₹2,86,350. That total is compared with the approval matrix to see whether a higher approval was needed.

Frequently asked questions

Is a single PO ever flagged?

No. A case needs at least two POs from the same supplier.

Can I use my own approval matrix?

Yes — type it in or upload an Excel file with From Amount, To Amount and Approval Level columns.

Is my PO data uploaded anywhere?

No. The file is processed in your browser tab. See the privacy note above for what the page itself loads from other servers.
